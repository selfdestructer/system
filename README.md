# Today's Lists

A shopping and to-do list that works out the exact part a list entry needs, finds it nearby or online, and plans the shortest trip out and back home.

The app lives in [`todays-lists/`](todays-lists/). Its README covers installing, starting the dev server, opening the app on a phone, running the checks and building for the claude.ai artifact preview.

```bash
cd todays-lists
npm install
npm run dev
```

Claude Code guidance for working on this repo is in [`CLAUDE.md`](CLAUDE.md) and the skills under [`.claude/skills/`](.claude/skills/).
